# Coffee Break with Partner

## Where it runs

| Role | System |
|------|--------|
| Runtime | **Sales Assistant** |
| Source of truth | This Cursor skill folder |

## Paste into Sales Assistant

Open [sales-assistant-mega-prompt.md](sales-assistant-mega-prompt.md) and paste **only** the block between the `~~~~` markers into Sales Assistant as the playbook / system prompt.

## What it produces

A coffee-break brief with:

1. What the partner does
2. Red Hat connection (public signals only; flag unknowns)
3. Industry lens + talking points
4. Opening script (60–90 sec) + 6–10 discovery questions + soft close
5. Sources / confidence notes

## Checklist

```
Coffee Break with Partner — [partner name]
[ ] Partner name confirmed
[ ] Optional context captured (attendee, goal, product focus)
[ ] What the partner does
[ ] Red Hat connection
[ ] Industry lens
[ ] Suggested script + questions
[ ] Brief approved / refined
```

## Guardrails

- Never invent partnership tier, certifications, joint customers, or deal registrations
- Prefer “public signal is limited” over fabricated intimacy
- Optimized for a 20–30 minute coffee, not a full account plan
