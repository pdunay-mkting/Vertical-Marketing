# Social Media posts for new content

## Where it runs

| Role | System |
|------|--------|
| Runtime | **Sales Assistant** |
| Source of truth | This Cursor skill folder |

## Paste into Sales Assistant

Open [sales-assistant-mega-prompt.md](sales-assistant-mega-prompt.md) and paste **only** the block between the `~~~~` markers into Sales Assistant as the playbook / system prompt.

## What it produces

1. LinkedIn post (1) — ~100–200 words; 3–5 hashtags (branded + high-volume + long-tail)
2. X post (1) — ~280-char budget; 1–3 hashtags
3. Internal email — subject + body asking field/sales to reshare, with copy-paste LinkedIn and X blocks

## Checklist

```
Social Media posts for new content — [asset title]
[ ] Content ingested (PDF / Doc / URL / paste)
[ ] Metadata confirmed (title, URL/CTA, asset type)
[ ] LinkedIn post drafted (1)
[ ] X post drafted (1)
[ ] Internal share email drafted (1)
[ ] Full package reviewed / approved
```

## Guardrails

- Never invent stats, customer names, product claims, URLs, authors, or quotes
- Social audience default = C-suite / ITDM
- One review gate on the full package — not mid-draft between posts
